# igui-editor v0.1.0

First tagged macOS build.

## Highlights

- **Color emoji** in the editor, split preview, terminal, Explorer/outline
  labels and tab labels. Emoji are drawn from the system color font at the
  advance the layout reserved, so caret/selection/soft wrap stay exact.
- **Explorer file icons** from the installed VS Code *Material Icon Theme*,
  read at runtime (no vendored artwork). The disclosure arrow has its own fixed
  slot; file and folder icons share one aligned column with a small gap.
- Searchable, grouped settings panel with switch/choice/number widgets, IME
  caret placement for fields, one-pass syntax + semantic glyph painting, and a
  highlight catch-up fix for large files.
- Minimum window size, dependency `opt-level = 2`, and a 12 MB release growth
  guard.

## Install

1. Download `igui-editor-0.1.0-macos-arm64.zip` and verify its SHA-256 with the
   `.sha256` asset.
2. Unzip and move `igui-editor.app` to `/Applications` (or anywhere).
3. Open it. The bundle is **ad-hoc signed**, not notarized; a downloaded copy
   may need `xattr -dr com.apple.quarantine igui-editor.app` or
   System Settings → Privacy & Security → Open Anyway.

Requires macOS 11+ on Apple Silicon (arm64). File icons need the VS Code
Material Icon Theme extension installed; emoji need a system color emoji font.

## Verification

- `scripts/check.sh --release`: unit + doc tests, headless self-check, release
  size gate.
- `codesign --verify --deep --strict` on the bundle.
- Built from a clean, pushed `master`; the tag and assets are produced by
  `packaging/release-macos.sh`.
